# Проверка в игре (с 5 ноября 2026)

Всё, что нельзя узнать без клиента Forever. В коде такие места помечены `-- VERIFY:`.

## Подготовка (один раз)
1. Установить WoW Forever, зайти персонажем, выйти.
2. Подключить аддон: `powershell -ExecutionPolicy Bypass -File tools\install.ps1 -AddOnsDir "<WoW>\_<папка Forever>_\Interface\AddOns"`.
3. Запустить BaryshSync: `python -m barysh_sync` из папки `sync` (или автозапуск: `tools\register-sync-task.ps1`).
4. В игре: `/barysh module Sync on` — включить связь с ПК (по умолчанию выключена).

## День 1: загрузка и отчёт
1. Аддон загружается без ошибок, в чате «Barysh … загружен». Если аддон помечен «устарел» — включить «Загружать устаревшие» и сообщить номер из шага 2.
2. `/barysh probe` → `/reload` (или кнопка «Сохранить»). Отчёт уходит в базу на ПК: номер Interface, сборка, каких функций API нет, зона, ключ аукциона.
3. У аукциониста: открыть аукцион. Окно Barysh встаёт справа. Нажать «Полный скан» → дождаться «Полный скан: N лотов» → `/barysh probe` → «Сохранить».

После шага 3 в отчёте есть: сколько лотов, сколько секунд ждали ответа, сколько миллисекунд и кадров шёл разбор, первые 5 строк ответа API как есть.

## Торговля (после первых сканов)
- [ ] Сделки: «Купить» у товара — игра называет цену, покупка проходит одним кликом (`COMMODITY_PRICE_UPDATED` → подтверждение). Если цена выросла — отмена с сообщением.
- [ ] Сделки: у вещи — «Найти» находит лот, «Купить» покупает (`PlaceBid`, событие `AUCTION_HOUSE_PURCHASE_COMPLETED`).
- [ ] Куда приходят покупки: сразу в сумки или почтой.
- [ ] Товар это или вещь: `GetItemCommodityStatus` и тип события поиска; совпадает ли с догадкой «стакается → товар».
- [ ] Выставление: «Выставить следующий» — `PostCommodity`/`PostItem`; коды сроков (`AH.DURATION`: 2 = 8 ч, 3 = 24 ч?); копейки в цене (`SupportsCopperValues`); когда игра просит подтверждение.
- [ ] Депозит: реальный (`CalculateCommodityDeposit`) против оценки 15% цены торговца.
- [ ] Свои лоты: `QueryOwnedAuctions` / `GetOwnedAuctionInfo`; «Снять» — `CancelAuction`, стоимость снятия (`GetCancelCost`).
- [ ] Торговец: кнопка у окна торговца, продажа через `UseContainerItem`; покупки у торговца попадают в учёт (`BuyMerchantItem`: количество в штуках или пачках).
- [ ] Банк: номера сумок банка (`Bags.BankContainers`), капитал видит банк.
- [ ] Почта: «Оплатить» у наложенного платежа (`AutoLootMailItem` платит и забирает?), «Вернуть», «Забрать» у своих.
- [ ] Обмен: панель у окна обмена, слот «Не будет обменяно» показывает чары; после обмена — запись или «Что это было?».
- [ ] Профессии: окно — `ProfessionsFrame` или `TradeSkillFrame`; `C_TradeSkillUI.GetRecipeSchematic` даёт реагенты и выход; цвета рецептов (`relativeDifficulty`); «Сделать следующее» — `CraftRecipe`.
- [ ] Shift+клик по предмету вставляет ссылку в поле списка (хук `ChatEdit_InsertLink`); перетаскивание предмета на список.
- [ ] Импорт/экспорт строкой со сжатием (`C_EncodingUtil.CompressString`).
- [ ] Подсветка выгодных лотов в стандартном окне аукциона — придумать по фреймам клиента.
