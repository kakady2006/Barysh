# Проверка в игре (с 5 ноября 2026)

Всё, что нельзя узнать без клиента Forever. В коде такие места помечены `-- VERIFY:`.

## Подготовка (один раз)
1. Установить WoW Forever, зайти персонажем, выйти.
2. Подключить аддон: `powershell -ExecutionPolicy Bypass -File tools\install.ps1 -AddOnsDir "<WoW>\_<папка Forever>_\Interface\AddOns"`.
3. Запустить BaryshSync: `python -m barysh_sync` из папки `sync` (или автозапуск: `tools\register-sync-task.ps1`).
4. В игре: `/barysh module Sync on` — включить связь с ПК (по умолчанию выключена).

## День 1: загрузка и отчёт
1. Аддон загружается без ошибок, в чате «Barysh … загружен». Если аддон помечен «устарел» — включить «Загружать устаревшие» и сообщить номер из шага 2.
2. `/barysh probe` → `/reload` (или кнопка «Сохранить»). Отчёт уходит в базу на ПК: номер Interface, сборка, каких функций API нет, зона, ключ аукциона.
3. У аукциониста: открыть аукцион. Внизу вкладка «Barysh» — нажать, окно Barysh открывается внутри аукциона. Нажать «Полный скан» → дождаться «Полный скан: N лотов» → `/barysh probe` → «Сохранить».

После шага 3 в отчёте есть: сколько лотов, сколько секунд ждали ответа, сколько миллисекунд и кадров шёл разбор, первые 5 строк ответа API как есть.
